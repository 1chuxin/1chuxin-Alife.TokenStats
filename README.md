# Token 用量看板插件

为 Alife 提供 Token 用量统计看板：屏幕圆环挂件 + 悬停展开卡片 + 本地控制台详情页，逐轮记录用量日志，**模型无关**（官方 OpenAI 插件、灵枢 LanguageModelRouter 等均可正确统计）。

## 功能

| 组件 | 说明 |
|------|------|
| 圆环挂件 | 圆环=缓存命中率，圆心=所选范围 Token 总量（超长自动缩写为 K/M/B）；点击圆环循环切换统计范围（本次会话 / 今天 / 近7天 / 近30天 / 累计） |
| 悬停卡片 | 总量、轮数、输入、输出、缓存命中、命中率 + 最近一轮明细；底部范围胶囊可点击切换，与圆环联动并记忆 |
| 控制台详情页 | 浏览器打开 `http://127.0.0.1:18790/`：实时仪表、范围统计（今天 / 近7天 / 近30天 / 总计 / 自定义日期区间）、用量明细（单天按小时一条，≥7天按天一条）、最近对话轮次（含每轮模型标记） |
| 插件配置页 | 未激活角色也可直接查看历史用量；圆环偏好设置；按时间段（精确到秒）清理或一键清空历史 |

## 安装与使用

### 1. 安装插件

将 `1chuxin.TokenStats` 整个目录复制到 Alife 的插件目录：

```
<Alife安装目录>/Storage/Plugins/1chuxin.TokenStats/
```

> 目录内需包含 `TokenStatsModule.cs`、`TokenStatsUI.cs`、`manifest.json`。

### 2. 启用插件

启动 Alife 并激活目标角色，插件随角色自动加载：屏幕出现圆环挂件即生效；停止角色时挂件自动移除（会话统计清零，历史保留）。

### 3. 查看用量

- **日常**：瞄一眼圆环 / 悬停展开卡片即可
- **详细**：点击卡片底部"详情页↗"，或浏览器打开 `http://127.0.0.1:18790/`
- **角色未激活时**：在 Alife 插件配置页（初心的小工具 → Token用量看板）直接查看历史统计

### 4. 配置（可选）

在 Alife 的插件配置界面可修改（高级参数已折叠）：

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `Port` | `18790` | 本地统计服务端口，被占用时自动向后扫描（共 20 个） |
| `RingRange` | `session` | 圆心数值统计范围：`session` / `today` / `d7` / `d30` / `total` |
| `RingSize` | `40` | 圆环挂件边长（像素） |
| `Width` | `300` | 悬停展开卡片宽度 |
| `Height` | `228` | 悬停展开卡片高度 |
| `GapBesideSwitch` | `12` | 挂件与"展开思考"开关的间距 |

### 5. 数据管理

用量日志以 JSONL 逐行存储于：

```
<Alife安装目录>/Storage/Tokenlog/usage-log.jsonl
```

每行一条对话轮次记录（时间 / 总量 / 输入 / 输出 / 缓存命中 / 模型）。在插件配置页可：

- **按时间段清除**：起止时间精确到秒，仅删除区间内记录
- **清空全部历史**：两步确认后删除整个日志文件

## 模型兼容性

统计基于框架的 `ChatBot.TokenUsed` 事件，与具体语言模型插件解耦：

| 模型插件 | 支持情况 | 说明 |
|----------|----------|------|
| Alife.Function.Language.OpenAI（官方） | ✅ | — |
| Alife.Plugin.LanguageModelRouter（灵枢） | ✅ | 已验证 `include_usage` 上报，同时兼容 `prompt_tokens_details.cached_tokens` 与 `prompt_cache_hit_tokens` 两种缓存字段 |
| 其他模型插件 | ⚠️ | 只要随流式回调上报 token usage 即可统计；模型名通过反射自动识别，识别不到时回退为插件类型名 |

## 通用性（跨设备）

- **无写死路径**：自动从进程工作目录 / 程序集位置定位 Alife 根目录，任意安装位置可用
- **端口容错**：默认端口被占用时自动向后扫描 20 个端口，无需手动改配置
- **区域设置无关**：所有日期键使用 InvariantCulture，非公历区域设置下不会损坏按天聚合
- **多实例安全**：跨实例文件读写加锁，避免并发损坏日志
- **仅本机访问**：HTTP 服务只监听 127.0.0.1 回环地址，不对外网暴露
- **旧数据迁移**：检测到旧版日志存于插件目录时自动迁移至 `Storage/Tokenlog/`

## 限制

1. **本地统计**：数据仅保存在本机 `Storage/Tokenlog/`，不上传、不跨设备同步
2. **缓存命中字段**：依赖模型端上报缓存命中信息，未上报的模型该项为 0
3. **历史模型名**：升级前写入的旧日志记录无模型标记，显示为空
